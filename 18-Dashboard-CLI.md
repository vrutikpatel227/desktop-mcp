# 18 — Developer Dashboard & CLI

## Dashboard
Optional web dashboard for Overview, Devices, Connections, Tools, Permissions, Workspace, Processes, Logs, Security and Settings.

## Dashboard actions
Manage device connections, permissions, enabled tools, workspaces, logs, token revocation and agent health.

## CLI
Production package must provide desktop-mcp.

## Commands
desktop-mcp init
desktop-mcp start
desktop-mcp stop
desktop-mcp status
desktop-mcp pair
desktop-mcp tools
desktop-mcp config
desktop-mcp logs
desktop-mcp doctor
desktop-mcp update
desktop-mcp emergency-stop

## Doctor
Check Node.js, MCP Server, Desktop Agent, authentication, workspace, PowerShell, Git and browser readiness.

## UX target
Install -> pair -> connect MCP client -> start working with minimal technical friction.
