# 24 — Acceptance Criteria & MVP

## Installation
Windows installer works; CLI works; agent starts; auto-start works; uninstall works.

## MCP
Handshake, tool discovery, execution, structured responses and structured errors work.

## Filesystem
Create, read, update, delete, search, move and copy work inside policy boundaries.

## Terminal
PowerShell, command execution, background processes, process logs and stop/restart work.

## Browser
Open URL, navigate, click, type, screenshot and text extraction work.

## Git
Status, diff, commit, pull and push work with policy controls.

## Security
Authentication, authorization, workspace sandbox, path traversal protection, command injection protection, SSRF protection, rate limiting, audit logging and secret protection work.

## Reliability
Agent reconnect, timeout handling, crash recovery, process cleanup and safe retries work.

## MVP scope
MCP Server, Desktop Agent, authentication, workspace sandbox, core filesystem, terminal/PowerShell/process management, project create/run/stop/logs, Git status/diff/commit/push and security permissions/confirmation/audit logs.
