# 25 — Delivery Phases & Definition of Done

## Phase 1 / MVP
Core MCP server, local agent, authentication, sandboxed filesystem, terminal, processes, project lifecycle, basic Git and security controls.

## Phase 2
Browser automation, GitHub, Gmail, Outlook, dashboard, multi-device, remote MCP and cloud gateway.

## Phase 3
Team management, RBAC, enterprise SSO, central policies, fleet management, advanced observability, plugin marketplace and organization-level MCP tools.

## Definition of Done
On a fresh Windows machine:
Installer -> Desktop Agent -> Pair Device -> Connect MCP Client -> AI discovers tools -> natural-language command -> MCP validation -> permission approval -> agent execution -> result returned.

No manual source-code editing should be required for normal setup and operation.

## Product success test
A developer connects a compatible AI client, gives a natural-language computer/project task, the system executes it securely end-to-end and returns a verifiable result without manual terminal work for every step.
