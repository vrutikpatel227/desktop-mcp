# 27 — Example User Workflows

## Files
"Desktop par ek folder bana." -> create_directory.
"Project ki saari files dikha." -> list_directory.
"App.tsx read kar." -> read_file.
"Navbar ka code change kar." -> inspect -> update_file -> verify.

## Development
"Next.js project create kar." -> initialize -> install -> run -> health check.
"Build errors check kar." -> inspect logs -> fix -> build/test.

## Git
"Git status check kar." -> git_status.
"Changes commit kar." -> status -> add -> commit.
"GitHub par push kar." -> validate remote -> push, with policy/confirmation as configured.

## Browser
"Localhost open kar." -> open_url.
"Website test kar." -> navigate -> inspect -> interact -> report.

## System
"Node version bata." -> system information.
"Kaunse processes chal rahe hain?" -> process listing.
"Port 3000 kis process ne use kiya?" -> process/port inspection.

## Email
"Aaj ke important emails dikha." -> search/fetch -> structured result.
"Is email ka summary bana." -> read permitted messages -> summarize.
Send/reply follows confirmation policy.
