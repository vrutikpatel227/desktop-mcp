# Desktop MCP Server

## Documentation Pack
This folder contains the Universal Desktop MCP Server PRD organized into developer-friendly Markdown files.

## Product
Universal Desktop MCP Server — MCP Server + local Desktop Agent.
Primary platform: Windows. Future: macOS and Linux. Protocol: Model Context Protocol (MCP).
Target users: developers, AI engineers, power users, teams.

## Core flow
Natural language -> AI tool call -> MCP validation -> policy -> Desktop Agent -> local execution -> verifiable result.
